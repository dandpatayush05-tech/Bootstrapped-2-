# Hackverse | Autonomous Hackathon Concierge & Event Operations Platform

**Hackverse** is a 24/7 centralized agentic operations platform built for **Learnathon 5.0 (GIET University & Incubatex)** and the **Smart India Hackathon (SIH 2026)**.

---

## 🚀 Key Modules Built According to Problem Statement 11

### 1. 💬 Central Knowledge & Rule Engine (`AI Concierge`)
- **Learnathon 5.0 Ingestion:** Schedules by year (2nd Year 78 teams, 3rd Year 58 teams, 1st & 4th Year), venues (Mega Auditorium 08:00 AM, Smart Classrooms 1 & 2), 50+50 marks evaluation rubric, coordinators (Dr. Raghvendra Kumar), and WhatsApp groups.
- **SIH 2026 Guidelines:** 6-member team rule (1 female member mandatory), SPOC nominations, 500-submission freeze cap per PS, ₹1,50,000 cash prizes, and 50/50 IP rights.
- **10 Domain Tracks & 45 Problem Statements:** Deep technical architectures, suggested datasets (Ego4D, PaySim, Qiskit, BMON, Tox21), and ML models.
- **Hackathon Playbooks:** 36-Hour Sprint Roadmap, 30-Day SIH Plan, 2-Minute Pitch Formula, and rubric weights.

### 2. 🔍 Automated Submission Compliance Auditor
- Pre-screens GitHub repositories, video demo links, README files, and track alignment.
- Computes real-time **Compliance Score (0–100%)** with itemized passing and warning checklists.
- Prevents instant disqualifications from private repos or broken permissions before judging cutoffs.

### 3. 👥 Hacker Matchmaking Engine
- Matches solo hackers and incomplete teams using complementary skill matrices (Frontend, Backend, AI/ML, UI/UX, Hardware, Pitch).
- Calculates compatibility scores (e.g. 98% Compatibility) and supports 1-click connection requests and profile broadcasting.

### 4. ⏱️ Live Event Telemetry & Phase Timeline
- Live countdown clock and active milestone stepper in `Asia/Calcutta` (IST).
- Real-time rotating telemetry ticker with proactive alerts (workshop calls, mentor office hours, T-4h code freeze, and catering notifications).

### 5. 🚨 Urgent Operational Escalation Dispatcher
- Triages technical, hardware, and logistical blockers into prioritized queues (**P1 Critical Blocker**, **P2 Mentor Consultation**, **P3 Logistics**).
- Routes directly to on-call organizers and technical mentors (`decode.ayush11@gmail.com` / `dandpatayush05@gmail.com`).

### 6. ✉️ Mentor AI Query & Email Dispatch Engine
- Interactive workflow allowing participants to state their specific technical questions, roadblocks, and table locations.
- Synthesizes a structured AI email draft directly addressed to **`decode.ayush11@gmail.com`**.
- Provides 1-click **Open in Gmail / Default Mail Client** (via pre-filled `mailto:` deep link) and instant server dispatch logging.
